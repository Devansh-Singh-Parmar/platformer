# Platformer

A 2D platformer built with Godot for Hack Club's Jumpstart Haven. You control a character who runs and jumps through a tile-based level, with gravity, a camera that follows the player, and a hand-placed TileMap level.

## How to run it locally

This project was made with Godot 
1. Clone this repository:

   ```bash
   git clone https://github.com/Devansh-Singh-Parmar/platformer.git
   ```

2. Open Godot, click **Import**, and select the `project.godot` file from the cloned folder.
3. Press **F5** (or the Play button in the top-right of the editor) to run the project.

## Controls

- **Move:** A / D or Left / Right arrow keys
- **Jump:** W, Up arrow, or Space
